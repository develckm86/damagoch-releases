# Damagoch 내려받기

데스크탑 화면을 돌아다니는 다마고치.

**[최신 버전 내려받기 →](https://github.com/develckm86/damagoch-releases/releases/latest)**

## Windows

- `Damagoch.Setup.x.y.z.exe` — 설치해서 쓴다 (시작 메뉴에 들어간다)
- `Damagoch.x.y.z.exe` — 설치 없이 바로 실행한다

처음 실행하면 "Windows의 PC 보호" 창이 뜰 수 있다 (코드 서명 인증서가 없어서).
**추가 정보 → 실행** 을 누르면 된다.

## 맥

- Apple Silicon(M1 이후): `Damagoch-x.y.z-arm64.dmg`
- Intel: `Damagoch-x.y.z.dmg`

처음 한 번은 앱을 **우클릭 → 열기** 하거나, **시스템 설정 → 개인정보 보호 및 보안** 에서 *그래도 열기* 를 누른다.
메뉴 막대 오른쪽 아이콘으로 쓴다 (Dock 에는 나오지 않는다).
